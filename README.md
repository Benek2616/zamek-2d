# 🏡 Eldoria – Przygoda

Kolorowa przygodówka 2D w miasteczku fantasy.

## Fabuła
Ktoś ukradł magiczny amulet Starszego. Porozmawiaj z mieszkańcami, znajdź klucz przy studni, otwórz piwnicę i odzyskaj amulet.

- Piekarz Marek
- Strażnik Olek
- Starszy Tomasz
- Mała Ania

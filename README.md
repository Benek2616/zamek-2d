# 🏰 Zamek 2D – duża mapa

Przygodówka 2D na telefon z rozbudowanym zamkiem.

## Co jest w grze
- Duża mapa (kilka sal + lochy + wielka sala)
- Pochodnie, regały, stoły, beczki, posągi, banery, tron, okna
- Klucz, latarnia, amulet
- Joystick + przycisk AKCJA
